# Порох и Знамёна

Стратегия в реальном времени для Android в духе эпохи пик и мушкетов (XVII век): добыча ресурсов, застройка поселения, большие армии и битвы с компьютерным противником. Все названия, графика и карта свои: графика рисуется кодом, без сторонних картинок.

## Как получить APK

Каждый пуш в `main` запускает GitHub Actions (вкладка **Actions**, «Сборка APK»). Готовый файл `PowderAndBanners.apk` появляется в разделе **Releases** репозитория. Скачайте его на телефон и установите (Android 8.0 и новее, нужно разрешить установку из этого источника).

Сборки подписаны одним ключом (`app/powder.keystore`), поэтому новая версия ставится поверх старой без удаления.

Собрать вручную (нужен Android SDK 35 и JDK 17):

```
./gradlew assembleRelease
```

## Как играть

- **Цель:** разрушить все здания и войска противника (красные).
- **Выбор:** тап по своему отряду или зданию; двойной тап — все такие же на экране; задержите палец и ведите — рамка выделения (или кнопка «Рамка»).
- **Приказы:** тап по земле — идти строем, по врагу — атаковать, по лесу, шахте или ферме — добывать (крестьяне). «Натиск» — идти и бить всех по пути.
- **Камера:** одним пальцем — двигать, двумя — масштаб, тап по мини-карте — перейти.
- Здание с выбранным обучением: тап по карте ставит точку сбора; тап по лесу или шахте — новые крестьяне сразу идут работать.

### Войска

- **Пикинёр** — дешёвый и стойкий, наносит коннице втрое больше урона.
- **Мушкетёр** — бьёт издалека и сильно, но долго перезаряжается.
- **Рейтар** — быстрая конница, хороша против стрелков и пушек.
- **Пушка** — бьёт по площади, разрушает здания.

## Устройство

- `app/src/main/assets/` — вся игра: `index.html`, `style.css`, `game.js` (HTML5 Canvas, без библиотек).
- `app/src/main/java/ru/argeda/powder/MainActivity.java` — оболочка WebView во весь экран, кнопка «Назад» ставит игру на паузу.
- Проверить игру можно и в браузере: откройте `app/src/main/assets/index.html`.
